# Чтец Qwen Streaming v0.2 — технический кандидат

Основа: неизменённая Qwen3-TTS Android v0.1.0 (MIT), зафиксированный upstream commit. Дополнение использует существующий в библиотеке JNI nativeSynthesizeStreaming, не правит C++ модель.

Что сделано: Reader с PDF/TXT, короткие фрагменты до 96 символов, Qwen NativeParams maxAudioTokens=160, потоковые аудиоблоки, кнопка отмены (после очередного нативного аудиоблока), WAV с синхронизацией заголовка после каждого аудиоблока, экспорт частичного WAV, восстановление записи при перезапуске, диагностика времени, фреймов и RTF, 15-секундный пробный тест перед пятиминутным.

**Ограничения**: если первый аудиоблок не появляется, JNI не позволяет немедленную отмену. Требуется принудительная остановка приложения через Android; данные последнего завершённого аудиоблока сохранены. Прерывание Studio не реализовано, только Reader. Не проверено на физическом телефоне. Изолированный applicationId требует отдельного скачивания модели и нового голосового профиля; уже установленные приложения не затрагиваются.

В настоящий момент MP3, EPUB, OCR, полноценный фоновый режим, долгосрочное возобновление с позиции книги не готово. По факту CI проверяет компиляцию, unit tests и наличие символа JNI; качество, скорость и фоновые ограничения проверяются на Android.
