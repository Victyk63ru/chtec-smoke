# Чтец — диагностика Qwen Reader (эксперимент)

Добавлена вкладка **«Журнал»** с кнопками **«Обновить журнал»**, **«Скопировать журнал»** и **«Сохранить отчёт TXT»**. В файл пишутся запуск/завершение/ошибка синтеза, время работы и количество готовых аудиофреймов раз в ~10 с; без текста книги или голосовой записи.

В **«Чтец»** остановка действует между фрагментами. **В Studio безопасного прерывания нативного синтеза пока нет.** Кнопку-обманку не добавляем. При зависании используется принудительная остановка приложения через настройки Android.

Из-за отсутствия исходного APK-ключа подписи новая тестовая сборка имеет **другой applicationId**. Она устанавливается отдельно и НЕ обновляет прошлую: модели (~884 МБ) и голосовой профиль придётся создать заново. До проверки производительности на устройстве не считать проблемой решённой. Исходные приложения и ветка main не меняются.
