# Чтец — MOSS Smoke A v0.4

Экспериментальное офлайн-приложение Android. На первом этапе проверяем только русский текст → WAV со встроенным голосом MOSS. **Персональный голос, PDF, MP3 и перевод пока не реализованы.**

Сборка: откройте вкладку **Actions** и workflow **Chtec MOSS Android smoke APK**. При коммите в main запускается автоматически. APK доступен в разделе Artifacts успешного запуска.

При первом запуске нажмите **«Скачать и проверить модели»** (около 760 МБ), затем включите авиарежим и **«Создать WAV»**. Для отправки ошибок используйте кнопку копирования журнала.

Нельзя считать сборку или офлайн-синтез проверенными до появления соответствующих результатов. Образы моделей хранятся только на телефоне, не в GitHub. Модели скачиваются с Hugging Face только при первом запуске.

Original upstream MOSS Android demo: https://github.com/OpenMOSS/MOSS-TTS-Nano/tree/31f42bae0a181849864c7ee39e8b88990909065f/examples/android_onnx_runtime
