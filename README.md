# Чтец — экспериментальный Smoke B (собственный голос)

Эта ветка проверяет **полностью локальное** клонирование пользовательского голоса на Android.
Основная ветка `main` сохраняет работающий Smoke A v0.4.

После обновления APK:
1. Скачайте/проверьте модели. Для кодирования голоса загрузятся ещё 2 ONNX-файла (~45 МБ).
2. Выберите личный WAV-файл (PCM16, 48 кГц, моно или стерео, 0,5–12 с). Он сохраняется **только в приватной папке приложения на телефоне**.
3. Введите короткий русский текст, создайте WAV.
4. Включите авиарежим и повторите тест.
5. Для диагностики скопируйте журнал.

Никакие голосовые записи, аудиотокены и сгенерированные записи не коммитятся в репозиторий и не отправляются на сервер. Модели скачиваются только при первом запуске.

**NOT RUN:** успешная компиляция экспериментальной ветки, кодирование голоса ONNX и звук на телефоне до испытания. Модель может не передать тембр или звучать неестественно.
