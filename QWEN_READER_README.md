# Чтец — Qwen Reader V0.1 / испытание

Эта ветка создаёт отдельный Android APK из точно зафиксированного MIT-кода
Danmoreng/qwen3-tts-android 35738304b31c425cc08fb5405372fedfd6531b3b.
Нативное ядро qwen3-tts.cpp не переписывается. MOSS в main не изменён.

Возможности: проверка извлечённого текста из PDF (только текстовый слой) / TXT UTF-8;
локальная пакетная озвучка выбранным голосовым профилем, фрагменты по 220
символов; цель 300 секунд звука или до конца импортированного текста;
потоковая запись PCM16 WAV; экспорт через Android SAF; ручная остановка между
фрагментами. Использует существующие экраны Voices / Studio / Settings.

Не готово: визуальный просмотр страниц PDF, OCR, EPUB, возобновление с позиции,
фоновый режим и MP3. Сканированные PDF не будут прочитаны. Для безопасности
при импорте пока читаются первые 35 000 символов документа до 35 МБ, первые
300 страниц. Полноценную книгу в одном запуске не обрабатывает.

Изолированный packageId com.yagel.chtec.qwenreader означает повторное скачивание
модели (~884 МБ) и создание голосового профиля заново. Личные голоса и записи
не включены в публичный GitHub; исходное приложение Qwen останется установлено.

QA: Gradle tests + Android CI + APK integrity. Реальный 5-минутный офлайн
тест требует проверки на телефоне. Не путать CI PASS с runtime PASS.
