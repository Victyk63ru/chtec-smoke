# Чтец — Qwen Safe v0.3

**Причина исправления**: по загруженному диагностическому журналу 2026-11-17, 09:36:46, JNI streaming вызов немедленно вернул null, попытка обращения к NativeResult.success привела к NPE. Звук не создавался. На данном этапе нет доказательств, какая из нативных проверок в JNI вернула null; поэтому потоковый JNI не используется.

**Что изменено**: используется **исходный nativeSynthesize()** из официального Android-приложения Qwen (путь, уже работавший на телефоне в Studio). Разбивка до 96 символов, сохранение готовой части WAV сразу после завершения каждого фрагмента; состояние/скорость и журнал; остановка **после текущего фрагмента**, экспорт частичного WAV. Первым запускается 15-секундный тест. Native core, MOSS main, сервисы ЯГЕЛЬ не изменены.

**Ограничения**: мгновенной отмены одной нативной операции нет; длительный первый фрагмент может занимать много времени. Реальная скорость/Qwen stability остаются NOT RUN до испытания на физическом телефоне. Отдельный идентификатор Android-приложения требует повторной загрузки модели и восстановления голосового профиля, поскольку debug-ключ предыдущего APK не был сохранён. Книги с изображениями без текстового слоя, полноценный фон и MP3 не поддержаны.
